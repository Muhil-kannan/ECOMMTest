# E-commerce Dashboard

A modern, responsive e-commerce administration dashboard built with React, TypeScript, and Tailwind CSS.

## Features
- **KPI Stat Cards**: Real-time business metrics with trend indicators.
- **Interactive Sales Chart**: Monthly revenue visualization using Recharts.
- **Recent Orders Table**: Detailed transaction history with status badges.
- **Responsive Sidebar**: Mobile-friendly navigation with Lucide icons.
- **Modern UI**: Clean SaaS aesthetic using Tailwind CSS.

## Tech Stack
- **Framework**: React 18 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Utilities**: clsx, tailwind-merge

## Getting Started

1. **Install Dependencies**:
   bash
   npm install
   

2. **Run Development Server**:
   bash
   npm run dev
   

3. **Build for Production**:
   bash
   npm run build
   

## Project Structure
- `src/components/layout`: UI shell components (Sidebar).
- `src/components/dashboard`: Feature-specific widgets (Charts, Tables, Cards).
- `src/data`: Mock data for demonstration.
- `src/types`: Shared TypeScript interfaces.
- `src/App.tsx`: Main application assembly.
