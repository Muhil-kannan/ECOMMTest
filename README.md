# E-Comm Store

A professional, high-performance e-commerce storefront built with React 19, TypeScript, and Tailwind CSS.

## Features
- 🚀 **React 19 & Vite 6**: Lightning fast development and optimized builds.
- 🛡️ **TypeScript**: Strict type safety across the entire application.
- 🎨 **Tailwind CSS**: Utility-first styling with a clean, modern aesthetic.
- 📱 **Responsive Design**: Mobile-first approach for all screen sizes.
- 🧩 **Modular Architecture**: Clean separation of concerns between layouts, pages, and features.

## Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   bash
   npm install
   
3. Start the development server:
   bash
   npm run dev
   
4. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Project Structure
- `src/components`: Reusable UI components (Layout and Feature-specific).
- `src/pages`: Main view components.
- `src/data`: Mock data and API simulation.
- `src/types`: TypeScript interfaces and types.
- `src/index.css`: Global styles and Tailwind directives.

## Scripts
- `npm run dev`: Start development server.
- `npm run build`: Build for production.
- `npm run preview`: Preview production build locally.
- `npm run lint`: Run ESLint for code quality checks.
